# 答案之书 | Book of Answers

一个模拟真实书籍翻页效果的 Web 应用，用户输入问题或数字后，通过逼真的 3D 翻页动画展示对应答案。

## 特性

- 📖 **逼真的 3D 翻页动画** - 使用 CSS 3D transforms 实现流畅的翻页效果
- 🎨 **精美的视觉设计** - 书籍质感、纸张纹理、金色封面
- 🎯 **双模式输入** - 支持数字直接索引或问题哈希索引
- 📱 **响应式设计** - 完美适配桌面、平板和手机
- 💾 **历史记录** - 自动保存最近 20 条查询记录
- 🎭 **300 条答案** - 包含正面、中性、负面、幽默、神秘哲理五大分类

## 在线体验

访问 [GitHub Pages](https://wujiang1999.github.io/book-of-answers/) 在线体验。

## 本地运行

1. 克隆仓库：
```bash
git clone https://github.com/wujiang1999/book-of-answers.git
cd book-of-answers
```

2. 直接用浏览器打开 `index.html` 即可运行，无需任何构建工具或服务器。

## 使用方法

1. 点击封面的"开始探索"按钮
2. 在输入框中输入你的问题，或输入 1-300 之间的数字
3. 点击"翻页寻找答案"或按 Enter 键
4. 欣赏逼真的翻页动画，查看你的答案
5. 可以点击"再翻一页"继续提问，或"返回"重新输入

## 技术栈

- **前端框架**：原生 HTML/CSS/JavaScript（零依赖）
- **动画效果**：CSS 3D transforms + transitions
- **数据存储**：localStorage（历史记录）
- **部署方式**：GitHub Pages（纯静态文件）

## 答案分类

| 分类 | 数量 | 比例 | 说明 |
|------|------|------|------|
| 正面答案 | 120 条 | 40% | 积极肯定、鼓励前进 |
| 中性答案 | 90 条 | 30% | 中性建议、需要思考 |
| 负面答案 | 60 条 | 20% | 警告、延迟、重新考虑 |
| 幽默答案 | 15 条 | 5% | 幽默回答、轻松一刻 |
| 神秘哲理 | 15 条 | 5% | 神秘哲理、深层思考 |
